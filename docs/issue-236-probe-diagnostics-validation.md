# Issue 236：失败状态与单节点测速诊断

验证日期：2026-10-12（Asia/Shanghai）。针对 issue 236 后续回复中“失败（历史）”、历史失败是否重测及单节点失败原因的问题。

## 已完成

- 本轮失败、核心超时和不可用分别显示；最新失败不会被旧成功或历史失败覆盖。以前成功的延迟和时间仅作为悬停参考，历史标记只用于旧成功测量。
- 帮助菜单增加“单节点测速诊断…”：选择一个实际节点、HTTP/HTTPS 测试地址及快速/完整期限。共享现有测速会话，不能与节点切换或其他测速并行；结果可以选择、复制。
- 记录节点/provider 身份、测试地址、核心与请求期限、开始/结束时间、耗时、Core API 状态及受控的失败分类。核心的 503 表示测速调用失败，不等于目标网站返回 HTTP 503。
- 独立核心的单节点失败接口保留兼容状态码，增加受控的 DNS、连接、认证、TLS、QUIC、HTTP 和未知错误分类；不直接输出原始错误、服务器凭据或连接地址。旧核心没有详细字段时明确显示原因未知。
- 请求结果按配置、远程实例、核心 generation、节点身份和取消状态校验。超时、重复和过期回调不得覆盖新状态。日志可关联具体节点，诊断报告包含当前作用域最近五次记录；测试 URL 去除用户信息、查询参数和片段。
